# Original research evidence

These measurements belong to the original 13-example language-design experiment, not to the converter's on-device AI or its counted lexical packages. The research report defines the display assumptions, grounding prior, corpus limitations, and semantic readings.

`Silex-Complete-Package.zip` preserves the original `outputs/` and `work/` layout, source scripts, metadata, and SHA-256 manifest. Extract it to reproduce the original report. The source copies in `reproduction/` are for inspection; their relative paths assume that original extracted layout. Generation uses Python, Pillow, ReportLab, and the recorded macOS fonts. Fonts are not redistributed.

The current converter's independently executed JavaScript tests use original Python-generated words, packets, and grids in `tests/fixtures.json`.
